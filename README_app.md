1. 設定層A 與 設定層B，A是benchmark的選擇，B是推理引擎的選擇 
2. 輸入層A 與 輸入層B，A是對設定層A的測試參數設定，B是對推理引擎參數的設定。A跟B都用表格的方式呈現，讓使用者條列出所有testcase 
3. 輸入整合層，條列出輸入層A與輸入層B的所有搭配組合，並允許使用者移除不需要測試的組合 
4. 執行層，啟動腳本開始執行，每次執行都會是啟動推理引擎、啟動benchmark、得到結果 
    4-1. 執行時應有兩種 log，一個顯示當前執行到哪裡，一個顯示執行細節 
5. 輸出整合層，根據benchmark的種類，可視化結果 
6. 匯出層，選擇寫入wandb或local

--
1. Benchmark 是固定的選項，目前暫定只有 "LLM_Metrics" 一個，在選擇後進入輸入層會有寫死的對應參數欄位，以及進入執行層後會有對應的腳本 
2. 推理引擎是固定的選項，目前暫定只有"vllm"，會有寫死的參數與腳本
